Rules that work: deny by default, allow by need, log what you block. 
1. Start from "block everything". 
2. Add specific allows: who, to what, using which service. 
3. Order matters: the firewall acts on the first rule that matches. 
4. Log what is blocked, and have someone review the logs. 
5. Filter outbound traffic too: a server that suddenly sends data to an unknown address is a 
warning sign. 
ISO/IEC 27001:2022 covers these in Annex A controls 8.20 (networks security), 8.22 (segregation of 
networks) and 8.23 (web filtering). 
IDS and IPS: the alarm and the guard 
IDS tells, IPS stops. An intrusion detection system (IDS) watches traffic or a computer and raises an alert. 
An intrusion prevention system (IPS) can also block what it finds. 
• 
Network-based systems watch traffic; host-based ones watch a single computer or server. 
• 
Signature-based systems look for known attacks; anomaly-based ones look for unusual 
behaviour, such as a large transfer at 2:00 AM. 
• 
Both raise false alarms, so IT tunes them. Their logs feed monitoring and, after an incident, the 
incident report. 
VPNs: a private tunnel 
A virtual private network (VPN) encrypts the connection between a remote computer and the office. 
• 
A remote-access VPN connects one staff laptop to the office; a site-to-site VPN connects two 
office networks. 
• 
Every VPN account needs MFA, and the accounts of people who leave are closed on their last 
day, as Module 2's contractor case showed.

Data moving (in transit) 
• 
Websites and portals: HTTPS, which uses TLS. The padlock means the connection is encrypted 
and the site's certificate was issued for that name by a certificate authority. It does not mean 
the site is honest; Module 4 returns to this. 
• 
Current versions: TLS 1.2 or 1.3. TLS 1.0 and 1.1 were formally deprecated in 2021 (RFC 8996). 
• 
Remote work: a VPN tunnel (Lesson 3.1). 
• 
File transfer: SFTP or HTTPS uploads, never plain FTP, which sends passwords and files 
unprotected. 
• 
Wi-Fi: WPA3, or WPA2-Enterprise with a personal login for each staff member; guests on their 
own network. 
• 
Email: personal data in attachments goes encrypted, or is replaced by a secure link with access 
control. NPC Circular 2023-06 requires secure transmission for emails that carry personal data. 
Data stored (at rest) 
• 
Laptops and phones: full-disk encryption, so a lost device does not mean lost data. 
• 
Databases and files: database or file-level encryption for sensitive personal information. 
• 
Removable media: office-issued encrypted USB drives only. NPC Circular 2023-06 requires 
encryption when personal data must move on removable media. 
• 
Backups: encrypted, with at least one copy kept offline.

Zero Trust is a strategy, not a product you buy. NIST Special Publication 800-207 sets out its principles: 
every resource is protected, all communication is secured whatever the network location, and access is 
decided for each request by policy. 
First steps for an office: list its people, accounts and devices; turn on MFA first for email, VPN and admin 
accounts; separate the network into zones; keep logs and look at them; review access on a schedule. 
MFA: know, have, are 
Multi-factor authentication asks for two or more kinds of proof: something you know (a password or 
PIN), something you have (a phone or a security key), and something you are (a fingerprint or face).

===== PAGE 9 =====
Passwords that work 
• 
Long beats complex: a passphrase of four or more unrelated words. 
• 
One password per account, kept in a password manager. 
• 
Never reuse an office password anywhere else. 
• 
Pwned Passwords checks whether a password has appeared in known breaches without sending 
it: only the first 5 characters of the password's hash are sent, never the password itself. In class 
we use invented passwords only. 
Roles, not people 
Role-based access control (RBAC) gives access to roles that match job functions, and people are given 
roles, not one-off permissions: roles, not people. 
• 
Least privilege: each role gets only what the job needs. 
• 
Two hands on money: separation of duties means no one person can both create and approve a 
payout, or change an e-wallet number and release the payment. 
• 
Joiner, mover, leaver: access is set up on the first day, changed on transfer, and closed on the 
last day, including for contract-of-service and job-order staff and consultants. 
• 
No shared accounts, least of all admin accounts. Admins use a separate admin account, only for 
admin work. 
• 
Access is reviewed every quarter, and every privileged action is logged. 
ISO/IEC 27001:2022 covers these in Annex A controls 5.15 to 5.18 (access control, identity management, 
authentication information, access rights), 8.2 (privileged access rights) and 8.5 (secure authentication). 
NPC Circular 2023-06 requires an access control policy, a security clearance filed with the DPO for those 
who may access personal data, and a password policy.
